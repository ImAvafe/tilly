# Tokens

Tokens _(or design tokens)_ are the values used throughout a user interface, like colors or spacing units.

Tokens are separated and queried by **namespace**, so to use them in utility tags, they need to be in the correct namespace. For example, `bg-red-500` and `text-red-500` both ingest the `color-red-500` token.

When you're defining your own theme's tokens, you'll need to make sure they're in the appropriate namespaces. Below is a reference:
